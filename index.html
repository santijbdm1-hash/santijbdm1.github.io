APPLICATION SPOTLIGHT

My Journal

My Journal is a personal activity and life tracking application created to eliminate the clutter of conventional planners and social tracking apps. It provides an intimate, notebook-like digital space centered around clarity.

Key Engineering Highlights

  • Structured daily activity logging (routines, deep work, leisure, background sessions).
  • Interactive goal-tracking with time-based milestone evaluations.
  • Daily reflections engine designed with calm typography and frictionless data capture.
  • Searchable historical library with intuitive temporal categorization.
 APPLICATION SPOTLIGHT

My Wallet

My Wallet is an approachable personal finance platform. Rather than overwhelming users with unnecessary complexity or bank integrations, it focuses on transparency, smart categorizations, and rapid transaction entries.

Key Engineering Highlights

  • Live financial summary dashboard with balance indicators and spending rates.
  • Real-time transaction tracking categorized by expenditure type.
  • Dynamic budget ceilings that communicate remaining discretionary spending.
  • Clean visual analytics highlighting trends and financial health over time.
